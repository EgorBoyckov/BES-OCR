# BES OCR

Локальное офлайн-приложение для Astra Linux 1.7, конвертирующее PDF
(текстовый, сканированный или смешанный) в редактируемый документ Microsoft
Word (`.docx`) с автоматическим восстановлением структуры: заголовков,
абзацев, списков и, что особенно важно, **настоящих редактируемых таблиц**
(со строками, столбцами и объединёнными ячейками), а не изображений.

Вся обработка (анализ PDF, OCR, генерация DOCX) выполняется локально, без
обращения к интернету и облачным сервисам.

## Возможности

* Текстовый слой PDF используется напрямую там, где это точнее; при его
  отсутствии/повреждении включается локальный OCR (Tesseract, ru+eng).
* Автоматическое обнаружение таблиц и объединённых ячеек — как на страницах
  с текстовым слоем (по линиям/выравниванию через `pdfplumber`), так и на
  сканах (по геометрии линий через OpenCV).
* Восстановление заголовков, абзацев, списков, выравнивания, отступов,
  изображений, колонтитулов, номеров страниц, разрывов страниц.
* Рукописный/нераспознаваемый текст сохраняется как изображение, а не как
  поток ошибочных символов.
* Современный GUI на PySide6: drag-and-drop, пакетная обработка нескольких
  PDF, прогресс, отмена, журнал, кнопка открытия папки с результатом.
* Потоковая/параллельная обработка страниц — работает с документами на
  100+ страниц без зависания интерфейса.

## Быстрый старт

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
sudo apt install tesseract-ocr tesseract-ocr-rus tesseract-ocr-eng   # если ещё не установлены
python -m bes_ocr
```

Подробности — в `docs/INSTALL.md`.
